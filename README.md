# Daily Planner
A responsive Daily Planner web application built using HTML, CSS and JavaScript.It helps users organize daily tasks with real-time progress tracking and persistent task storage using Local Storage.

## Features
- Add new tasks
- Mark tasks as completed
- Delete individual tasks
- Clear all completed tasks
- Filter tasks (All, Active, Completed)
- Real-time progress tracker
- Saves tasks using Local Storage
- Responsive design for desktop and mobile

## Technologies Used
- HTML5
- CSS3
- JavaScript
- Local Storage API
